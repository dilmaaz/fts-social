# FTS Social

Social media posters for FTS Elevators & Escalators (Instagram @ftselevator, Facebook), scheduled through Metricool.

- `posters/` — finished 1080x1350 posters, named `fts-YYYY-MM-DD-topic-vN.jpg`.
- `assets/photos/` — approved photos from getfixable.com to use as poster backgrounds.
- `assets/logo/` — official FTS logo (SVG masters + PNG renders). Never redraw or retype the logo.
- `tools/make_poster.py` — renders a poster in the house style: `python3 tools/make_poster.py spec.json out.jpg`.
